# Diagrama CLD (Causal Loop Diagram) — com explicação

Documentos de design do diagrama CLD, exportados do Claude Design. Os arquivos
`.dc.html` são abertos no navegador e dependem de `support.js`, `cld-data.js` e
de `_ds/` por caminhos relativos — **mantenha esta estrutura de pastas**.

| Arquivo | Conteúdo |
|---|---|
| `Plano UX do Diagrama.dc.html` | Plano de UX do diagrama |
| `Diagrama CLD.dc.html` | Versão 1 do diagrama |
| `Diagrama CLD v2.dc.html` | Versão 2 do diagrama |
| `Diagrama CLD 3 camadas.dc.html` | Versão em 3 camadas (Problema · Compensação · Solução emergente) |
| `Diagrama CLD 3 camadas v2.dc.html` | Versão 2 em 3 camadas (mais recente) |
| `cld-data.js` | Dados do diagrama (camadas, cores, nós) |
| `support.js` | Runtime dos arquivos `.dc.html` |
| `_ds/` | Design system RiscoCognitivoBlog (CSS/JS/tokens) |
| `uploads/` | Imagens de referência (IMG_3698–3700) |
