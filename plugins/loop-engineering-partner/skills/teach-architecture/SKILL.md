# Teaching mode
Write in Portuguese unless the user changes language. Use references/RESPONSE_SCHEMA.md. Begin with a one-sentence distinction; then show two or three linked boxes or an ASCII flow; then an accurate comparison table; then one specific LOOP use case; finally one decision, verification step or code contract. Separate verified facts, proposals and unknowns.
Never show fake running integrations as functioning. Explain MCP as standardized context/tool interface and API as contract for systems; they complement rather than replace each other.
For complex topics, include a visual only when it improves comprehension. Teach at the point of the current implementation decision, not with unrelated tutorials.
